RESEARCH FOR HUMANS — FORMAT SPECIFICATIONS
Screen and printouts — as implemented in app.py, 2026-05-28
==========================================


PRINTED LABEL (4 × 3 inch card)
---------------------------------
Canvas:         1200 × 900 px at 300 DPI
Background:     white
Margins:        0.15 in (45 px) on all sides
Copies:         2 per response
Printer:        Primera LX500, CUPS name PTI_Color_Label_500, PageSize=4x3


ICON (label)
-------------
Source file:    icon.png (project root)
Height:         same as QR code — 1.0 cm (118 px at 300 DPI)
Width:          proportional to source aspect ratio
Position:       bottom-left corner of label, top-aligned to reference strip (ref_y)
                left edge at left margin


BODY TEXT (label)
------------------
Font:           Arial (regular), 46 pt
Bold font:      Arial Bold (or Verdana Bold as fallback), 46 pt
Line height:    58 px
Color:          black (0, 0, 0)
Alignment:      left, starting at left margin
Top edge:       top margin (icon no longer at top)
Bottom edge:    stops when next line would overlap the reference strip
Paragraph gap:  half line height (28 px) for blank lines between paragraphs
Bold:           opening sentence only, wrapped in ** by the model and
                rendered in bold font
Max chars:      480 characters (enforced before printing)


REFERENCE STRIP (label)
------------------------
Height:         1.0 cm = QR code height (118 px at 300 DPI)
Position:       bottom of label, above bottom margin
Layout:         single QR code (right) + first author name stacked left of QR
QR:             1.0 cm × 1.0 cm, right-aligned to right margin
Author name:    stacked lines (First [MI.] / Last / et al. if multi), right-aligned
                to 8 px left of QR, top-aligned to QR, gray (85, 85, 85)


QR CODES
---------
One QR code per response (not per paper)
Size:           1.0 cm × 1.0 cm (118 × 118 px)
Position:       bottom-right corner of label (above bottom margin)
Error correction: Medium (ERROR_CORRECT_M)
Links to:       /refs/<uid> — lit-review page with all retrieved passages and full citations
                When printed from localhost, URL is rewritten to the machine's LAN IP
                so phones on the same network can scan and reach the page
Colors:         black on white
Persistence:    /refs pages are held in memory (_ref_cache dict). If the app
                restarts, old QR codes will not resolve. This is expected —
                restart the app once each morning at the conference.


AUTHOR NAMES (label)
---------------------
Font:           Arial, 24 pt
Line height:    30 px
Color:          gray (85, 85, 85)
Alignment:      right-aligned to left edge of QR code (8 px gap)
Position:       top-aligned to QR code
Format:         stacked lines —
                  line 1: First [Middle Initial.]
                  line 2: Last
                  line 3: et al.  (only if more than one author)


RETRIEVAL (what papers get cited on the label)
-----------------------------------------------
Query method:   cosine similarity via ChromaDB + nomic-embed-text embeddings
Results pulled: 7 nearest chunks (N_RESULTS = 7)
Chunk cap:      700 characters per chunk (MAX_CHUNK_CHARS)
Papers cited:   up to 3 unique papers (deduplicated by title from top 7 results)
Context sent to model: ~5,000–7,000 chars (~1,200–1,800 tokens)


RESPONSE FORMAT (oracle card)
------------------------------
Total length:   480 characters maximum (hard limit, enforced by _truncate_reply)
Structure:      two paragraphs separated by one blank line
  Para 1:       one bold sentence (opening aporia or claim)
                contains at least one word/theme from the input question
                short, stands alone without context
  Para 2:       1–3 plain sentences of evidence from corpus + closing question
                must end with a question mark
                no section labels

Punctuation:    periods, commas, question marks only
                no em-dashes, en-dashes, colons, semicolons, parentheses
                (enforced by _enforce_format post-processing)

Citation line:  appended automatically as "— First Author et al. (Year)"
                not counted in the 480-char limit
                not generated by the model


ON-SCREEN PREVIEW
------------------
Size:           exactly 4 in × 3 in (matches physical card)
Border:         1px solid #ccc
Padding:        12 px
Font:           Arial, 12 px, color #555
Background:     white
Body:           flex:1, overflow hidden, white-space pre-wrap
Ref strip:      "References for this response here:" link to /refs/<uid> (8 px, right-aligned)
                Single QR code (38 × 38 px) linking to /refs/<uid>, bottom-right of preview
Bold rendering: **text** converted to <strong> via JS regex


WEBSITE UI
-----------
Background:     white
Max width:      1100 px, centered
Font:           Arial throughout

Icon (site):    icon.png at native size, centered, 12 px margin below
Instruction:    16 px, full container width, 1.5 line height

Question input row:
  Width:        80% of container
  Border:       bottom only, 1px solid black
  Input font:   Arial 12 px, color #555
  Placeholder:  10 px, color #bbb
  Auto-resize:  height grows with content

Sub-instruction text:
  Width:        80% (same as input row)
  Font:         12 px, line height 1.2
  Alignment:    left
  Margin:       3 px above

Loading animation:
  Three dots, 10 × 10 px each, color #000 (black)
  Pulse animation, 1.4s cycle, staggered 0.2s per dot

Print button (TESTING mode only):
  Color:        #C8FF00, hover #b8ef00
  Label:        "Print ×2"
  Font:         13 px bold, letter-spacing 0.03em
  Appears:      after response renders
